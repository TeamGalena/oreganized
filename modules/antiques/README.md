## 📖 About:

This module includes the **Tarnished Antiques**.

These are piles of aged silverware that can be found placed in monster rooms, 
as well as items in some chests or by digging them up in archeologic sites.

By polishing them using the brush, you can turn them into on of many loot items,
like silver armor, tools or various devices.
