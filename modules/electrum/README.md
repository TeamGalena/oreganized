## 📖 About:

This module includes all the **Electrum** features.

It's a new metal alloy made from [silver][SILVER] and gold.
Can be used to upgrade tools & armor as an alternative to netherite.
The armor grants increased movement speed, while the tools deal additional damage based on their users velocity.
