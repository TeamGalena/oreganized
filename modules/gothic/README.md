## 📖 About:

This module includes the **Gargoyle**, the **Crystal Glass** and the **Grimstone** block set.

The gargoyle is a decorative blocks that can be placed on the floor or the against the side of a block.
Feeding it a silver ingot lets it emit a growl that will scare undead mobs away.
You can also use it with a comparator to read out how far away the closest undead mob is.

Crystal glass is a new type of decorative stained glass with pretty patterns.
It has built-in support for [Dye Depot][DYE_DEPOT].

Pointed dripstone can be turned into dripstone spyres by placing them under a silver block and letting water drip through.
